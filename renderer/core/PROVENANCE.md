# Renderer core provenance

`renderer/core/` is the product copy of the selected S-A2 native Direct3D 12 core, with W-J's per-piece pose path added as ABI 3, the product API as ABI 4 and route B as ABI 5. Every ABI 1 to 4 source was copied from the selection evidence under `work/experiments/` at commit `0f067202ae16ee981db7eef2ece05b54fe226b98`. ABI 5's route B parts are adapted from the C9 present probe `work/experiments/c9-present-probe/` (commit `c47efdca`, PR 245); route B is accepted for now by the owner on 18 Nov 2026, pending three owner-machine checks (`docs/wiki/decisions/owner-decisions-2026-11-18-route-b.md`). That evidence stays read-only: the build compiles nothing from `work/experiments/`, and `tests/test_renderer_core.py` checks the digests below against it.

Each row pairs one product file with one source. A product file built from two sources has two rows. "verbatim" means that the product file's SHA-256 equals the source digest. A product file with no source is marked `new`.
