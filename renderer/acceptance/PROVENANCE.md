# Acceptance harness provenance

`renderer/acceptance/` is the run harness for the C9 acceptance runs on the product core `renderer/core/` (ABI 5; the texture routes use only ABI 1 to 3 calls, route B also ABI 5's `sa2_create` and surface calls, and a stage build also ABI 5's four user-stage calls, C9 U5c). Its Godot project and run scripts were copied from the S-A2 selection evidence under `work/experiments/` at commit `0f067202ae16ee981db7eef2ece05b54fe226b98`. That evidence stays read-only: the harness builds and writes nothing under `work/experiments/`, and `tests/test_renderer_acceptance.py` checks the digests below against it. W-J's data exporter `work/experiments/renderer-wj/prepare_wj.py` is not copied; `prepare_data.py` runs it in place, unchanged, and the run finalizer imports the gate `tools/perf/renderer_gate.py` from the repository.

Each row pairs one harness file with one source. A file built from two sources has two rows. "verbatim" means that the harness file's SHA-256 equals the source digest. A file with no source is marked `new`.
