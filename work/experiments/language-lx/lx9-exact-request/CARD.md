The packet restricts work to this directory and forbids network use. No nested
review-wrapper call, external handoff access, installation or personal-data
access is performed. Integrator review stays outside this implementation call.

Production, from the repository root:

```text
python -B work/experiments/language-lx/lx9-exact-request/freeze.py
```

This is an explicit writer, separate from acceptance. It captures inputs,
recomputes both routes, writes tables and refreshes the experiment's own pins.
Normal acceptance never calls it:

```text
python work/experiments/language-lx/lx9-exact-request/check.py
```

The full check needs Python and `rustc` on PATH. The Python fixtures require
only the standard library and support CPython 3.14. A deliberately partial
check without Rust is available; it prints that the default-grid run was omitted:

```text
python -B work/experiments/language-lx/lx9-exact-request/check.py --python-only
```

All temporary products, including the compiler's temporary directory and
executable, stay in `build/`. Both production and acceptance remove it in
`finally`. Acceptance checks frozen digests, compares regenerated bytes and
checks that its retained-file snapshot is unchanged. It writes no timing,
report, digest, bytecode cache or generated binary that remains.
