## Observation log

### [2026-10-18] Research viewer findings

1. **RO-01.** A general jumbled state can give every piece its own pose, so up to 177,120 rigid 4D transforms: about 11.3 MB as float32 4 × 4 matrices, about 5.7 MB as unit-quaternion pairs. During a twist only the moving set changes. Evidence: `research/jumbling/viewer/README.md:210-213`. For this line: W-J uploads the whole table on each revision (`work/experiments/renderer-wj/RESULT.md:5`); a partial upload changes a shared path and must keep the revision check over all bound data (`docs/progress/1.0/packets/renderer/E-2.4-0J-jumbling.md:63`).
2. **RO-02.** Every animated twist leaves the slot grid for its whole moving cap, retained twists included. Evidence: `research/jumbling/viewer/README.md:214-216`. For this line: in Jumble mode the moving set comes from the engine as sorted piece ids with a SHA-256 (`research/jumbling/render-contract.md:73`), not from slots.
3. **RO-03.** Shrink must be applied in the piece's home frame before its pose, and 4D back-face culling must use each sticker's posed facet normal, not its slot's cell normal. Evidence: `research/jumbling/viewer/README.md:217-219`. For this line: W-J shrinks in the home frame (`docs/progress/1.0/packets/renderer/E-2.4-0J-jumbling.md:61`) and draws with no culling (`work/experiments/renderer-sb/SPEC.md:51`); any culling added later must use posed normals.
4. **RO-04.** The outer shape stops being the polytope: after one 10° twist, 3,789 of 6,499 patch stickers had a vertex outside the 600-cell, and projections of neighbouring cells can interpenetrate. A world-fixed cell cage was needed to see the change. Evidence: `research/jumbling/viewer/README.md:220-223`. For this line: W-J draws no cage (`work/experiments/renderer-wj/README.md:120`), and no renderer packet covers the raw view's overhangs (`docs/progress/1.0/jumbling-observation.md:94`).
5. **RO-05.** At the witness state S1, 16,938 of the 20,136 straddling certificates use a region vertex that lies on no sticker. Evidence: `research/jumbling/viewer/README.md:224-226`. For this line: certificate points come only from engine fields (`research/jumbling/render-contract.md:86`).
6. **RO-06.** A blocked grip had 181 to 827 straddling pieces at S1 (median 345). The highlight read only when the other pieces dimmed, and one focus piece with a pager was needed. Evidence: `research/jumbling/viewer/README.md:227-229`. For this line: the straddling overlay needs dimming and a focus piece; its W-J cost is unmeasured (`work/experiments/renderer-wj/RESULT.md:65`).
7. **RO-07.** Grip status exists only at exact states, so the WebGL markers turn neutral during motion and both views carry an exact or preview badge. For this line: the W-J snapshot is a probe choice, not a product rule; a drawn status belongs to one revision (`docs/progress/1.0/jumbling-observation.md:35`).
