# The project's own language

This folder holds the architecture of the project's own language (working name C600 Script). Under the
[owner's decision of 3 November 2026](../../../wiki/decisions/owner-decisions-2026-11-03.md), the engineering line
develops the language first, beginning with its complete ecosystem and architecture. Every document here is a draft for
the owner. The owner accepts ADRs and freezes the architecture.

| Document | What it is | Status |
| --- | --- | --- |
| [Ecosystem partition and owner questions](ecosystem-partition.md) | The components and their boundaries; what restoration and the research need; the option sets for the boundary of tools a solver develops; the implementation-route options; the phases; the owner's questions | Draft, step 1, revised after DT-L1 rounds 1 and 2 and the plan check |
| Architecture document | The full text, one chapter per layer and pillar | Written after the owner confirms the direction |
| ADR drafts | One record per architectural decision | Written after the owner confirms the direction |

The round table for the language is [DT-L1](../../../progress/1.0/design-table/topics/language-ecosystem.md), with the
mathematician and the engineer advisor.
