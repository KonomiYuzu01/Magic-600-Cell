## 1. Goal and acceptance

The tutorial needs about a hundred puzzle pictures (owner decisions of 22 October 2026,
`docs/wiki/decisions/owner-decisions-2026-10-22-figures-and-merge.md`, decisions 1 and 3). Build the batch path and
one framing change:

1. `V/make_figures.py --list F/figures.json --out F [--vendor DIR] [--check]`:
   - `figures.json` (format `magic600-tutorial-figures/1`) is a list of entries `{id, record, step, when, view, proj,
     emph, ghost, cap, w, h}`; `record` is a repository-relative run directory (`…/run`), `cap`, `ghost`, `w` and `h`
     are optional; `id` matches `^[a-z0-9][a-z0-9-]{0,63}$` and is unique;
   - exports each distinct `(record, step, when)` once with `V/export_tutorial.py` into a fresh temporary directory,
     captures every entry with one run of `V/capture_tutorial.mjs`, and writes `F/png/<id>.png`;
   - writes `F/manifest.json`: per figure its entry, the export's `tutorial.json` fields that fix the state (record,
     `run_sha256`, the word hashes, step, when, digest, moved count, off-lattice count), the capture parameters and
     the PNG sha256; plus the tool versions and page digests from the capture manifest; no absolute paths;
   - `--check` exports and captures again into a temporary directory and compares every PNG sha256 and every state
     digest with `F/manifest.json`; exit 1 and name the figures that differ;
   - removes files in `F/png/` that are not in the list only with `--prune`; otherwise reports them;
   - refuses records with start seeds 9011..9073 (the exporter already does) and any `record` outside the repository.
2. **Framing for ghost-free pictures.** With `ghost=none`, the local and global views frame the emphasised stickers'
   projected extent (all of them, posed), centred on that extent, filling about 80% of the shorter side, instead of
   the cap's cells. With ghosts, framing stays as it is.
3. `V/test_make_figures.py` (unittest, no browser): list validation (bad id, duplicate id, record outside the
   repository, reserved seed), the export de-duplication, manifest content and absence of absolute paths, using a
   stub in place of the capture step. Add a short "Tutorial figures" note to `V/README.md`.

Acceptance (the contract's check): `V/test_make_figures.py` and `V/test_export_tutorial.py` pass (one command below).
Your sandbox cannot start Chromium; the integrator runs the captures and `V/check_full.mjs`.

Out of scope: choosing the figures (the integrator writes `F/figures.json`), captions, annotations, colours, other
renderers, performance.

## 2. Actual problem and reproduction

Each picture now takes a manual export and a hand-written capture list. With `ghost=none` the local view frames the
cap and its four face neighbours, so the moved pieces of a step fill only about a third of the image.
